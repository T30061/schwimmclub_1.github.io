# ASKÖ Swimclub Neusiedl Website

## Project order

1. Home page: `index.html`
2. About page: `pages/about.html`
3. Programs page: `pages/programs.html`
4. Schedule page: `pages/schedule.html`
5. Events page: `pages/events.html`
6. Gallery page: `pages/gallery.html`
7. Contact page: `pages/contact.html`
8. Shared styling: `assets/css/styles.css`
9. Shared behavior: `assets/js/script.js`

## Structure

- `index.html` – main landing page and club overview
- `pages/about.html` – club story, design inspiration, values
- `pages/programs.html` – lesson and squad details
- `pages/schedule.html` – weekly timetable
- `pages/events.html` – club events and community activities
- `pages/gallery.html` – visual club gallery
- `pages/contact.html` – inquiry form and club contact details
- `assets/css/styles.css` – complete design system and responsive styling
- `assets/js/script.js` – navigation and dark mode functionality

## Design direction

The project follows the brief in `INFOS.md` with a modern swim club look:

- large, bold typography
- sports-first composition
- airy layout with strong white space
- premium blue and white palette with warm accent tones
- dark mode support for every page
